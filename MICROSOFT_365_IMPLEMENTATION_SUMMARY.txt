4. OAUTH FLOW
================================================================================

1. User clicks "Connect Microsoft 365"
   → POST /api/integrations/microsoft-365/authorize
   → Receives authorization URL

2. Redirects to Microsoft login
   → User authenticates with Microsoft account
   → User grants permissions (Mail.Read, Calendars.Read)

3. Microsoft redirects to callback
   → GET /api/integrations/microsoft-365/callback?code=...&state=...
   → Server exchanges code for tokens (client_secret server-side only)
   → Tokens stored encrypted in Supabase
   → Redirects to /dashboard with success message

4. Dashboard shows "Connected" status
   → User can click "Disconnect" to revoke access
   → POST /api/integrations/microsoft-365/disconnect
   → Tokens cleared, integration marked as disconnected

### **Policy by Action Type**

| Action | Run Out Mid-Action | Behavior |
|--------|--------|--------|
| **Cloning** | Balance → 0 at 45% | ⏸️ PAUSE - can resume after top-up |
| **Code edit** | Balance → 0 mid-edit | ❌ STOP - refund partial cost, no partial edit |
| **Page build** | Balance → 0 mid-build | ❌ STOP - refund partial cost, no partial page |
| **File generate** | Balance → 0 mid-generate | ❌ STOP - refund partial cost, no partial file |
| **Asset analysis** | Balance → 0 at 75% | ✅ SHOW PARTIAL - offer upgrade for full |
| **Content analysis** | Balance → 0 at 60% | ✅ SHOW PARTIAL - offer upgrade for full |

---

### **Why Different Policies?**

**STOP & REFUND (Atomic Operations):**
- Cloning, code edits, page builds = all-or-nothing
- Cannot save partial clone/edit/page (broken state)
- Refund unused PC if stopped mid-action
- EXCEPTION: Cloning can PAUSE (restore later)

**SHOW PARTIAL (Progressive Operations):**
- Analysis = partial results still valuable
- User gets insights even if cut short
- Upgrade option to see full analysis
